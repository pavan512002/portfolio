TapCourt Live Scoring

Live badminton scoring with a full BWF rules engine — one Flutter codebase shipping to web, Android and iOS, with real-time score sharing and offline support.

FlutterDartNode.jsPostgreSQLRedisSSE

How it works

1 · BWF rules engine

A complete badminton scoring engine — rally scoring, intervals, game/match point, sudden death, serve tracking and undo — ported 1:1 from a tested JavaScript engine into Dart.

2 · One codebase, three platforms

Flutter ships the same app to web, Android and iOS: a broadcast-style scoreboard, thumb-zone scoring controls, scorer PIN lock, and a live rally feed.

3 · Real-time score sharing

Every rally is mirrored to a Node.js + PostgreSQL + Redis backend and streamed over Server-Sent Events — a public watch link lets anyone follow the score live, no account needed.

4 · Offline-first

A persisted retry queue holds every rally in order and replays it against the server when the network returns — scoring never stops.
