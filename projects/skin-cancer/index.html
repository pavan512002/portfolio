Skin Cancer Detection

A deep learning system that classifies skin lesion images — built on transfer learning with a MobileNetV2 backbone, tuned for accuracy across multiple lesion classes.

PythonTensorFlowMobileNetV2OpenCVCNN

How it works

1 · Preprocessing pipeline

Lesion images go through an OpenCV + TensorFlow pipeline — resizing, normalization, and augmentation — so the model generalizes instead of memorizing.

2 · Transfer learning backbone

A pre-trained MobileNetV2 extracts visual features, bringing the power of a model trained on millions of images to a medical dataset.

3 · Custom classification head

Specialized dense and dropout layers are stacked on top of the backbone and trained for multi-class skin lesion classification.

4 · Robust predictions

Dropout regularization and augmentation keep the model honest — high accuracy on the classes it was trained for, without overfitting.
